# KRA Metrics Reference

The HR supplied reference currently contains role-specific KRA sheets and a set of HRMS-oriented metrics discussed for result-driven evaluation. These are reference material only.

The application intentionally does **not** seed or auto-assign generic/default metrics. HR must configure the expected result metrics for each department and designation.

Current HRMS-oriented metrics discussed:

| Category | Expected result | Weight |
|---|---|---:|
| Attendance & Reliability | Meet department attendance expectations | 15% |
| Task Completion | Complete assigned work with evidence | 25% |
| Deadline Adherence | 90–100% on-time delivery | 15% |
| DPR Submission | 100% of expected working-day DPRs | 15% |
| Quality & Accuracy | 95%+ quality/accuracy | 15% |
| Collaboration & Ownership | Consistent proactive ownership | 15% |

These values are not automatically loaded into employee KRA templates. HR can choose, change or replace them when configuring each designation.
